Thank you for downloading the Wellness AI Coach App. This documentation will guide you through the process of setting up the frontend of the application, ensuring you can run and test it locally with ease.

Flutter Installation & Setup
Running the App

1. Installation Requirements

To ensure smooth operation, make sure you have the following setup:

  • Flutter SDK
  • Dart SDK
  • Android Studio or Visual Studio Code
  • Android Emulator or Physical Device

2. Downloading and Installing Flutter

Follow the official guide to install Flutter on your system:

Flutter Installation Guide

Step 1: Clone or download the project

Access the project files from the provided source or download the compressed package and extract it to your local machine.

Step 2: Install dependencies

Open the terminal in your IDE and run the following command to install all the required dependencies:

flutter pub get

Step 3: Run the App

Connect an emulator or physical device and launch the app using:

flutter run
